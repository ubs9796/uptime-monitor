# Contributing

- Keep the flat layout and Python standard library only. No new dependencies.
- Run `pytest -v` before opening a PR; all tests must pass.
- Use a `feat/<slug>` branch and Conventional Commits.
- Never commit `.env`, `sites.json`, `*.db`, tokens, chat IDs, or webhook URLs.
- Keep changes small, add tests for behavior changes, and update the README.
